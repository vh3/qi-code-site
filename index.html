Qi Code

Morse Trainer for iPhone

Qi Code teaches International Morse code the way operators actually learn it: by ear, as rhythm. Characters arrive a few at a time, and each one always plays at full speed, with extra space between characters while you are still slow.

  • Works completely offline — no account, no connection
  • 26 letters, 10 digits, and period, comma, and question mark
  • Every sound mirrored by a visual pulse, with optional vibration
  • Sending never requires timed pressing
  • Progress stays on your device; nothing is collected

Qi Code is a generic Morse code trainer. It is not affiliated with, endorsed by, or licensed by any Scouting organization.
